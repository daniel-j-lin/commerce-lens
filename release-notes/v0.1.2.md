# CommerceLens v0.1.2 - Explicit Schema Mapping UX

- Human-readable CSV/XLSX headers can now be proposed for source-to-canonical mapping.
- Non-identity mappings require explicit user confirmation before material analysis.
- User corrections override mapping proposals.
- Ambiguous or insufficient mappings remain blocked.
- Exact canonical inputs remain zero-friction.
- Deterministic `validate_mapping(...)` remains authoritative.
- No new Metrics or analytical claims were added.
- P11 fail-closed safety behavior remains preserved.

Known limitation:

Common date and monetary-format robustness remains narrow and is planned for the next milestone.
