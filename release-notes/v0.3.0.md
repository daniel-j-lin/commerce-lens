## First diagnostic method

`weekly_product_presence_revenue_association@1.0.0` tests product-presence Jaccard distance against weekly Revenue deviation using deterministic Spearman rank association for the single approved `product_composition_association` family.

The governed MVP analytical decision boundaries are:

- rho <= -0.50 → `CRITERION_MET`
- -0.50 < rho < +0.50 → `CRITERION_NOT_MET`
- rho >= +0.50 → `PROPOSITION_CONTRADICTED`

These are analytical decision boundaries, not statistical-significance thresholds. `CRITERION_MET` is not causality, a sole/primary-cause determination, a `ClaimDecision`, or a `Finding`.

## Limitations

The diagnostic result is non-causal and covers one method only. Time trend, seasonality, promotions, inventory, demand, customer mix, discounting, and external conditions remain possible alternative explanations. External validation is not established.
