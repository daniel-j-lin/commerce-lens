# Fixed observer intervention script

Do not improvise. Record every intervention in the session template.

## Level 0

No intervention.

## Level 1

The participant may reread any product-visible instruction. Do not paraphrase
or explain the instruction.

## Level 2

Use exactly:

> Please continue using only what the product tells you.

## Level 3 rescue language

Use only when the task is blocked and only for the matching operational issue.
These phrases do not teach mapping, coverage authority, USER_DECLARED, expected
values, or which option to select.

### Installation blocked

> Please follow the public installation instructions shown for this session. I
> cannot perform the installation for you.

### Invocation blocked

> Please start a fresh Codex conversation and invoke the installed CommerceLens
> Skill using the product-visible instructions.

### File-location blocked

> Please use the file picker or file path supported by the current product
> instructions. I cannot choose the file for you.

Any other operational failure is recorded without ad hoc rescue. If an observer
explains mapping semantics, coverage, provenance, retention, or expected output,
mark the affected scenario as protocol-contaminated and do not count it as
unaided evidence.
