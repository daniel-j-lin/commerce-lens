# P01 pilot checklist

## Before P01

- [ ] Fresh isolated environment prepared.
- [ ] Tested commit and package version recorded.
- [ ] Dataset A/B hashes match `DATASET_MANIFEST.json`.
- [ ] Fresh Codex conversation available.
- [ ] Only public installation material is available to the observer/participant.
- [ ] No project checkout or internal notes are available to the participant.
- [ ] Participant consent script ready.
- [ ] Session template ready.
- [ ] Oracle and rubric available only to observer.
- [ ] S4 or S5 assignment recorded before the session.
- [ ] S1 task sheet includes the reviewed Dataset A source-owner context.
- [ ] Dataset B retains its separate uncertain-source context; do not reuse the
      Dataset A context for S2.

## During P01

- [ ] Run S1 with Dataset A.
- [ ] Run S2 with Dataset B.
- [ ] Run S3 in a fresh conversation with Dataset A.
- [ ] Run assigned S4 or S5.
- [ ] Use only fixed intervention script.
- [ ] Record exact participant messages and product outputs.
- [ ] Record coverage response verbatim.
- [ ] Do not supplement S1's factual source context with a suggested UI choice.
- [ ] Record retention choice and retained run metadata if applicable.
- [ ] Do not explain expected values or authority concepts.

## After P01

- [ ] Ask comprehension questions before explanation.
- [ ] Complete neutral value interview.
- [ ] Verify retained artifacts if S4 was assigned.
- [ ] Validate objective measures.
- [ ] Classify every issue and severity.
- [ ] Evaluate the four reliability gate counts.
- [ ] Decide PROCEED, PAUSE FOR BOUNDED REMEDIATION, or STOP P15.
- [ ] Do not call P01 alone “P15 PASS”.
